# Twitch badge chat

Имитация чата Twitch для проверки канальных значков (Creator Badge Drops, значки подписчика) перед загрузкой на Twitch.

Сайт: https://alkatrazzjr.github.io/twitch-badge-chat/

## Как пользоваться

- Значок слева в поле ввода → «Имя в чате»: ник, роль, значок канала, общий значок, цвет имени.
- Каждое сообщение запоминает значки, с которыми оно отправлено. Сообщения хранятся в браузере зрителя.
- ⚙ → «Значки»: создать свою категорию, загрузить/удалить свои значки. Значки всех категорий видны и доступны всем.

## Права

- У каждого браузера свой секретный ключ (создаётся автоматически). Категория и её значки принадлежат этому ключу:
  удалять их может только он. Ключ можно перенести на другое устройство («Перенести права…»).
- IP используется только для антиспама (лимит категорий и загрузок), не как права — один IP бывает у многих людей.
- Владелец: откройте сайт один раз как `…/twitch-badge-chat/#admin=<ADMIN_KEY>` — браузер получит право удалять всё.
  Ключ лежит в `admin-key.txt` (не в git) и в секрете Worker `ADMIN_KEY`.

## Устройство

- `index.html`, `style.css`, `app.js` — статический сайт на GitHub Pages.
- `rules.js` — правила Twitch, общие для сайта (живая проверка) и сервера (окончательная проверка).
- `worker/` — Cloudflare Worker + D1 (категории, значки, PNG). Деплой: `cd worker && npx wrangler deploy`.
  Схема: `npx wrangler d1 execute twitch-badge-chat --remote --file schema.sql`.
  Локально: `.dev.vars` с `ADMIN_KEY=…`, `npx wrangler dev --port 8791 --ip 127.0.0.1 --local`, сайт на `http://localhost:8765/`.

## Требования к значкам (по документации Twitch)

**Creator Badge Drops** ([Twitch Help](https://help.twitch.tv/s/article/creator-badge-rewards), лимиты подняты в августе 2026):
квадратный PNG без анимации, до 25 КБ, рекомендуется от 120×120; название до 25 символов;
в событии до 3 значков — за подписки/подарки (1–100, обязательный), за просмотр (до 24 ч), Top Supporter (топ 1/3/5/10);
событие не дольше 28 дней, одновременно активно только одно (в пределах категории).

**Значок подписчика** ([Subscriber Badge Guide](https://help.twitch.tv/s/article/subscriber-badge-guide)):
три PNG 18×18, 36×36, 72×72 с прозрачным фоном, каждый до 25 КБ.

**Общий значок** — для имитации глобальных значков (на Twitch их выдаёт только Twitch): квадратный PNG до 100 КБ.
