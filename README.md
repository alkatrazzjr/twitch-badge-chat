# Twitch badge chat

Имитация чата Twitch для проверки канальных значков (Creator Badge Drops, значки подписчика) перед загрузкой на Twitch.

Сайт: https://alkatrazzjr.github.io/twitch-badge-chat/

## Как пользоваться

- Чат общий для всех в реальном времени (последние 150 сообщений). Смайлы: Twitch (глобальные), 7TV, BTTV, FFZ —
  глобальные и канала; меню смайликов — кнопка справа в поле ввода.
- Значок слева в поле ввода → «Имя в чате»: ник (уникальный, закреплён за браузером), цвет, роль, значки.
  Как на Twitch — максимум 3 значка в строке: роль, подписка, один дополнительный (дроп / Bits / подарки / общий).
- «Значки пользователей» там же: дерево **ник → категории → значки**, любой узел сворачивается.
  В своей ветке: «Новая категория», в категории — загрузить PNG или ZIP, переименовать, удалить.
  Файлы `N_18.png`, `N_36.png`, `N_72.png` → значок подписчика (N мес.); любой другой PNG → значок канала.
- Клик по нику в чате — карточка пользователя (перетаскивается за шапку).

## Права

- У каждого браузера свой секретный ключ. Ник и категории принадлежат этому ключу: менять/удалять их может только он.
  Ключ можно перенести на другое устройство («Перенести права…» в «Имя в чате»).
- Владелец (`…/#admin=<ADMIN_KEY>` один раз в браузере): удаляет сообщения, очищает чат, управляет любыми
  категориями и значками. Ключ лежит в `admin-key.txt` (не в git) и в секрете Worker `ADMIN_KEY`.
- IP используется только для антиспама.

## Устройство

- `index.html`, `style.css`, `app.js` — статический сайт на GitHub Pages.
- `rules.js` — правила Twitch, общие для сайта (живая проверка) и сервера (окончательная проверка).
- `worker/` — Cloudflare Worker + D1 (категории, значки, PNG) + Durable Object `ChatRoom` (общий чат по WebSocket, ники).
  `GET /twitch` — глобальные значки Twitch (через api.ivr.fi, кэш сутки). Деплой: `cd worker && npx wrangler deploy`.
  Схема: `npx wrangler d1 execute twitch-badge-chat --remote --file schema.sql`.
  Локально: `.dev.vars` с `ADMIN_KEY=…`, `npx wrangler dev --port 8791 --ip 127.0.0.1 --local`, сайт на `http://localhost:8765/`.

## Требования к значкам (по документации Twitch)

**Creator Badge Drops** ([Twitch Help](https://help.twitch.tv/s/article/creator-badge-rewards), лимиты подняты в августе 2026):
квадратный PNG без анимации, до 25 КБ, рекомендуется от 120×120; название до 25 символов;
в событии до 3 значков — за подписки/подарки (1–100, обязательный), за просмотр (до 24 ч), Top Supporter (топ 1/3/5/10);
событие не дольше 28 дней, одновременно активно только одно (в пределах категории).

**Значок подписчика** ([Subscriber Badge Guide](https://help.twitch.tv/s/article/subscriber-badge-guide)):
три PNG 18×18, 36×36, 72×72 с прозрачным фоном, каждый до 25 КБ.

**Общий значок** — для имитации глобальных значков (на Twitch их выдаёт только Twitch): квадратный PNG до 100 КБ.
